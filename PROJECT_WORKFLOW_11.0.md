# Project Workflow 11.0

## User path
DEMO → ANALYZE → MAP MUSIC → DIRECT SONG → MASTER → VERIFY → FINALIZE PROJECT

## Final bundle
- `PROJECT.json` — manifest and state
- `01_DEMO/` — source demo
- `02_MASTER/` — latest master when available
- `03_REPORTS/` — production report
- `04_WRITING/LYRICS.txt`
- `04_WRITING/SUNO_PROMPT.txt`
- `05_NOTES/NOTES.txt`

This is intentionally a portable delivery package, not a replacement for a DAW project.
