# Clarify

Read the active `specs/*/spec.md` and `.specify/memory/constitution.md`.

Find only ambiguities that can materially change scope, security/privacy, user experience, or acceptance criteria. Convert them into concrete questions with a small set of implications. Do not invent requirements.

After answers or a justified default, update the spec and re-check that every requirement remains testable and unambiguous. Do not implement code here.
