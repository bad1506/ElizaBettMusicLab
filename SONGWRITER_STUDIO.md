# Songwriter Studio 6.6

## Workflow
IDEA → HOOK → CHORUS → VERSE → BRIDGE → FINAL.

## Editor
The lyric canvas is editable. Generated drafts become versions. The user can switch versions, edit directly, analyze, and save to Artist DNA.

## QA
A lightweight heuristic checks structure, repetition, word variety, approximate syllable spread and singability. It is explicitly not a substitute for a human/melodic read.

## Trend separation
Trend research remains dated evidence and is not automatically written into Artist DNA.
