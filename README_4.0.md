# Eliza Bett Music Lab 4.0

Локальная AI audio workstation: Deep Audio Analysis → AI Decision Engine → Adaptive Master Engine → Iterative QC → Final Master.

## Запуск
1. Убедись, что `C:\ElizaBettMusicLab\.venv` существует.
2. Открой `run_lab.bat` из этой папки.
3. Открой `http://127.0.0.1:5173`.

Frontend больше не использует Tailwind/PostCSS, поэтому старую ошибку `Cannot find module tailwindcss` проект не должен получать.

## Профили
- Suno 6 · Commercial
- Suno 5.5 · Balanced
- Clean Streaming

Профили ориентированы на типовые задачи коммерческого AI-generated audio и не являются копией закрытой обработки Suno.
