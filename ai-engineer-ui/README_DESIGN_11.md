# Eliza Bett Music Lab — UI 11.0

Visual direction: premium dark glassmorphism inspired by modern iOS surfaces.

Palette:
- Peach `#FFC6A8`
- Soft peach `#FFE0CF`
- Burgundy `#741A2F`
- Deep wine `#4C1020`
- Near-black `#100608`

Principles:
- translucent frosted panels with subtle 1px outlines;
- warm peach as the primary action/highlight color;
- burgundy used as depth and state color;
- restrained blur, soft shadows, and rounded 13–22px geometry;
- no purple gradients and no generic SaaS dashboard styling;
- responsive layout with compact horizontal navigation on smaller screens.
