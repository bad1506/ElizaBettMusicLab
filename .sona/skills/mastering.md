# Mastering Skill

## Goal
Create a controlled final master without chasing loudness at the expense of musical impact.

## Workflow
1. Inspect the source and reference if present.
2. Choose a target based on genre, platform and requested character.
3. Control peaks and low-end before final loudness.
4. Preserve transients and stereo stability.
5. Compare before/after at matched perceived loudness.
6. Report target LUFS, ceiling, processing profile and QC status.

## Rules
- Never claim a master was created unless the backend actually created a file.
- Never hide clipping, severe phase problems or missing input.
- Prefer a safe balanced result when the user does not specify an aggressive target.
