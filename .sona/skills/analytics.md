# Analytics Skill

## Goal
Turn artist and release metrics into decisions, not vanity numbers.

## Workflow
- Identify platform, period, release and comparison baseline.
- Separate reach, engagement, conversion and retention.
- Flag meaningful changes rather than normal noise.
- Explain likely causes and what to test next.
- Never invent unavailable statistics.

## Output
Metric -> change -> interpretation -> risk/opportunity -> next experiment.
