# Trends Skill

## Goal
Turn current music-market signals into useful creative decisions rather than generic trend lists.

## Workflow
1. Define market: country, platform, genre, audience and time window.
2. Gather current signals with web research when freshness matters.
3. Separate observation from interpretation.
4. Identify reusable patterns in hooks, topics, formats, visuals and release behavior.
5. Convert patterns into original track, content and release ideas.
6. Give confidence and source context for important current claims.

## Output
Prefer: trend -> evidence -> why it matters -> SØNA idea -> execution example. Never present stale or invented data as live.
