# Trends Skill

## Goal
Turn current music-market and social signals into useful creative decisions rather than generic trend lists.

## Workflow
1. Define market: country, platform, genre, audience and time window.
2. Search current sources when freshness matters.
3. Separate observation from interpretation.
4. Run FIT → SAFETY → TIMING before recommending a trend-jacking idea.
5. Identify reusable patterns in hooks, topics, sounds, formats, visuals and release behavior.
6. Convert patterns into original track, content and release ideas.
7. State confidence and source context for important current claims.

## Output
Prefer: trend → evidence → why it matters → SØNA idea → execution example → next test.

## Connected skills

Never present stale or invented data as live and never promise virality.
