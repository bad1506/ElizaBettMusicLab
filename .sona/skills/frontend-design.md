# SONA Frontend Design Skill

## Visual direction
Premium liquid-glass music intelligence interface: quiet light surfaces, deep graphite assistant panels, translucent borders, restrained lavender/cyan/pink light, large editorial type and purposeful whitespace.

## Interaction
- Every clickable control has visible hover, focus and pressed feedback.
- Pointer light follows the cursor on major glass surfaces without blocking interaction.
- Motion is short, smooth and action-driven; respect reduced-motion preferences.
- Mobile chat behaves like a real floating sheet, not an inline page block.
- Never add a decorative white browser-like frame around an input.

## Product rules
Navigation must work, buttons must have a real action, errors must explain the recovery path, and loading states must never look like a broken blank card.
