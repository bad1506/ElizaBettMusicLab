# Audio Analysis Skill

## Goal
Translate measurable audio characteristics into decisions a musician can act on.

## Review order
1. Input validity and file format.
2. Loudness and headroom.
3. Peak / true-peak risk.
4. Dynamics and crest behavior.
5. Frequency balance and masking.
6. Stereo image and phase risk.
7. Arrangement problems that EQ alone cannot solve.

## Output
Return a concise diagnosis, severity, likely cause, and concrete fix. Never fabricate measurements. If audio data is missing, state exactly what must be uploaded or measured.
