# Project Skill

## Goal
Turn a musical idea into a persistent project with a clear next action.

## Workflow
- Capture title, type, status, brief and current version.
- Preserve lyrics, prompts, notes, references and generated outputs.
- Track milestones: idea -> writing -> production -> master -> release.
- Make every project card actionable: open, continue, duplicate or export.
- Keep user history attached to the authenticated account when available; use local draft persistence as a fallback.
