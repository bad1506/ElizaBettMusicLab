# Release Marketing Skill

## Goal
Help an artist move from finished music to a coherent release campaign.

## Workflow
1. Define the song's promise, audience and emotional trigger.
2. Build positioning, one-line pitch and visual direction.
3. Create a release calendar with pre-release, release-day and post-release actions.
4. Generate platform-native content rather than copying one caption everywhere.
5. Track conversion signals: saves, completion, comments, profile visits, clicks and streams.
6. Iterate from actual results.

## Output
Deliver ready-to-use hooks, captions, short-form concepts, creator outreach angles, press copy and a measurable release plan.
